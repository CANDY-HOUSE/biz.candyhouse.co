## 概要

Biz3 は [CANDY HOUSE](https://jp.candyhouse.co/) のエンタープライズ向け Web 管理プラットフォームで、React で構築されています。

主な機能：

- 🔐 SESAME スマートロックデバイスのリモート管理・監視
- 👥 企業メンバーおよびゲストの権限管理
- 💼 認証機器（カード、パスワード、指紋、顔認証、掌紋）の設定・管理
- 📔 デバイス操作ログの閲覧
- 💳 Stripe サブスクリプションおよび決済管理

技術スタック：

- フロントエンドフレームワーク：React
- バックエンドサービス：AWS Amplify、Cognito 認証、DynamoDB、APIGateway websocket API
- 決済：Stripe
